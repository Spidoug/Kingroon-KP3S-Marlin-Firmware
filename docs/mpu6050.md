# MPU6050 / IMU — KP3S Marlin Firmware V1

The V1 uses software I2C on one fixed physical pair:

- SDA -> FFC17 / PD9 by default
- SCL -> FFC16 / PD8 by default

`SDA/SCL Inv.` exchanges the logical roles immediately and auto-saves the choice.

## Detection

The bus is scanned from `0x08` to `0x77`. An ACK alone is not accepted as an MPU. Discovery is non-destructive until identity is plausible: normal WHO_AM_I identity is accepted anywhere on the scan, while clone fallback without a normal ID is restricted to the official `0x68/0x69` strap addresses and read-only register sanity checks. Only then may reset/wake/configuration writes occur. Configuration is read back (`SMPLRT_DIV`, DLPF, gyro/accel range and power registers) and a plausible live 14-byte frame is required. Reads use repeated START with STOP/START fallback, retries and bus recovery.

## Normal processing

The toolhead-mounted MPU is used for three continuous signals. Their dedicated Nokia screens explicitly re-arm Marlin's graphical redraw state on every pass, so values keep changing while the screen remains open:

1. **Live level** — complementary accelerometer/gyro orientation. Accelerometer authority is reduced during strong carriage acceleration.
2. **Motion / vibration** — high-pass toolhead acceleration summarized as RMS, peak and instantaneous g.
3. **IMU die temperature** — `TEMP_OUT / 340 + 36.53 °C`, corrected by a persistent user offset, plus `DT` from an independent early sensor-temperature baseline. Angular zero calibration never resets this thermal reference.

Normal firmware sampling is 50 Hz idle and 100 Hz while printing. Complementary-filter, bias-learning and vibration-decay constants are time-based, so changing sample rate does not change their physical response time.

## Resonance assistant

The resonance assistant is under `KP3S Setup > Motion / Tuning > Resonance / Shaping`.

During a test the MPU temporarily uses the full configured 200 Hz sample rate. V1 records 192 samples for all three sensor axes, giving roughly 0.96 s of capture. The selected machine axis performs a bounded 10 mm peak-to-peak broadband reversal. The captured response is analyzed with a Bartlett-windowed Goertzel scan from 20 to 80 Hz and a 0.25 Hz local refinement around the strongest response. Confidence noise excludes the ±2 Hz resonance skirt so a broad real peak is not penalized as its own noise.

Safety rules:

- printer must not be printing, paused or have queued motion;
- tested axis and Z must already be homed;
- Z must be at least 5 mm above the bed before horizontal excitation;
- the movement must fit inside configured machine bounds;
- existing shaping is restored before the result is judged;
- X requires at least 45% confidence;
- Y requires at least 60% confidence because the head-mounted sensor only sees Y through the bed/frame structure;
- low-confidence or incomplete captures never change Input Shaping.

A successful result is applied with Marlin's native shaping frequency setter and saved through Marlin settings. The MPU therefore affects later print movement through Input Shaping, not by changing each G0/G1 command in real time.

## Level at startup

The startup check begins automatically as soon as the MPU is detected. While it is collecting data the Nokia footer shows `LEVEL/NIVEL: xx%`, so the user can see that the assessment is actually running. Forty quiet samples are accumulated in one coherent idle window. Minor vibration gaps are tolerated briefly, but a gap longer than 250 ms, obvious head motion, active printing or resonance capture prevents samples from different positions being mixed. The accepted result remains highlighted for about 60 seconds and is always available in `Startup Level / Nivel Inicial`.

`Calibrate Level Zero / Calibrar Zero Nivel` now opens a live calibration screen instead of saving immediately. Raw fused X/Y values keep updating continuously. After at least 500 ms of stable motion, pressing OK stores a settled/filtered mechanical mounting reference in EEPROM rather than a single instantaneous sample; pressing OK again returns. Clearing or changing zero invalidates only the previous startup-level accumulators. The independent `DT` temperature baseline is intentionally preserved.

This is a frame/toolhead orientation check only; BLTouch remains responsible for the bed surface and G29.

## Temperature

Because the module is attached to the extruder/toolhead, its die temperature can be higher than room temperature. `Temp Offset` is a persistent calibration from -30.0 to +30.0 °C. `Temp. IMU` shows corrected die temperature and `DT` from startup; it is not presented as ambient temperature.
