# Security and safety

This project can command motors and heaters. A software regression can cause injury, fire, hardware damage or loss of a functional control interface. **Do not flash unverified firmware or rely on simulator-only tests for physical safety.**

If you discover a security or safety vulnerability, use GitHub's **private vulnerability reporting** for this repository if the maintainer has enabled it. Otherwise, contact the repository maintainer privately through a channel they have provided; do not publish exploit steps or potentially dangerous heater/motion sequences in a public issue.

For non-sensitive problems, open an issue with the exact project revision, motherboard model, thermal profile and sanitized logs. Never include personal information, access tokens, private keys or device secrets.

This repository does not promise vulnerability response times or hardware certification.
